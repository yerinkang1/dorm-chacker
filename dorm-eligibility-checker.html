기숙사 입실 자격 판정 도구

규정: 도보·대중교통(무환승) 둘 다 30분 이상이어야 입실 가능 (대중교통 무환승 경로가 없으면 도보 기준만 적용)
안내. 이 도구는 카카오(주소→좌표), ODsay(대중교통 경로) API를 브라우저에서 직접 호출합니다. 두 서비스 모두 사전에 등록한 도메인에서만 호출이 허용되므로, 이 파일을 실제로 올릴 도메인을 카카오 개발자 콘솔과 ODsay 콘솔의 "플랫폼(Web)"에 등록해야 정상 동작합니다. Claude 미리보기 화면에서는 도메인이 고정되지 않아 API 호출이 막힐 수 있습니다.

API 키 설정

두 키 모두 이 브라우저(도메인)에만 저장됩니다. 서버로 전송되지 않습니다.

판정 기준 (조정 가능)

도보 소요시간은 직선거리 기반 추정치(우회계수 1.3, 도보속도 분당 67m)이며, 대중교통은 환승 없이 이동 가능한 노선 중 최소 소요시간입니다.
판정: 도보와 대중교통(무환승) 둘 다 기준 시간 이상이면 입실 가능, 하나라도 미만이면 불가능. 무환승 대중교통 경로가 없는 경우엔 도보 기준만으로 판정합니다.

셔틀버스 노선 및 탑승지 등록

노선을 먼저 만들고, 그 안에 탑승지를 추가하세요. 이후 노선 개편으로 탑승지가 바뀌면 각 탑승지를 개별 수정하거나 삭제/추가할 수 있습니다.

직원 주소 판정

한 줄에 한 명씩 입력하세요. 형식: 이름,주소 (이름 생략 시 주소만 입력해도 됩니다)

사내용 도구 · 좌표/경로 데이터는 카카오·ODsay API 결과에 따르며, 도보 소요시간은 추정치입니다.
